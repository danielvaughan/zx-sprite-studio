## What CC BY-NC 4.0 covers

| Path | What it is |
| --- | --- |
| `assets/` (all files except `assets/sources/loading/draw_scene.py`) | the loading and Start screens, their picture sources, prompts and working images |
| `docs/` | the user guide, the build history and the README pictures in `docs/images/` |
| `specs/` | the Sprite Studio specification and its notes |
| `game/video/` (all files except `*.py` and `recipes/`) | the tutorial video, the presenter clips and their sound, the voice script, lines and timeline, the edit list and the end screen |
| `game/media-kit/` | the tape-loading video and its posters |
| `game/playtest/`, `game/ux/`, `game/verify/shots/` | playtest and trial reports and their screenshots |
| `game/src/gen/library.json`, `game/src/gen/library*.bin`, `game/library-tapes/index.json` | the Library: sprite figures from Dalex Software's own games (Mower Mayhem, Tiger Gorilla, Gold Master, Antigravity, All Disco and WOLF) |
| `game/src/gen/start.rle` | the Start screen picture, packed |
| Markdown files (`*.md`) anywhere else in the repository | written records: design, decisions, milestones, status and these licence notes |

The tapes in `game/build/` hold both the program (MIT) and the pictures and Library figures (CC BY-NC 4.0).
Sharing a tape means following both licences, so a tape may be shared for non-commercial use only.
